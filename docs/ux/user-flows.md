# Fluxos de Usuário

## Fluxo principal

```text
Cadastro
↓
Workspace pessoal
↓
Onboarding
↓
Primeira conta
↓
Dashboard
↓
Nova receita ou despesa
```

## Fluxos a detalhar

- Cadastro e login
- Recuperação de senha
- Onboarding
- Criar conta financeira
- Criar receita
- Criar despesa
- Marcar como pago
- Reverter pagamento
- Cancelar transação
- Criar transferência
- Arquivar conta
- Arquivar categoria
