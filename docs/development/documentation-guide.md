# Guia de Documentação — YuFinance

## Finalidade

Este documento define como a documentação do YuFinance deve ser escrita
e organizada.

O objetivo é permitir que tanto desenvolvedores experientes quanto
pessoas que ainda estão aprendendo consigam entender o projeto.

## Princípios

A documentação deve:

- explicar antes de aprofundar;
- utilizar português simples sempre que possível;
- explicar termos técnicos quando aparecerem pela primeira vez;
- explicar siglas;
- explicar decisões importantes;
- apresentar exemplos quando ajudarem na compreensão;
- manter os nomes reais utilizados no código;
- apresentar a tradução de termos técnicos relevantes;
- explicar por que determinados nomes foram escolhidos.

## Estrutura recomendada

Cada documento deve começar, quando aplicável, respondendo:

1. O que é este documento?
2. Para que ele serve?
3. Quando devo consultá-lo?
4. Como ele se relaciona com o YuFinance?

Depois dessas informações começa o conteúdo específico do documento.
## Nomenclatura técnica

O código-fonte utiliza inglês como idioma principal para identificadores
técnicos.

Ao introduzir um conceito importante, a documentação deve explicar:

- nome utilizado no código;
- tradução para português;
- significado dentro do YuFinance;
- motivo da escolha daquele nome.

Exemplo:

`workspaceId`

Tradução: identificador do espaço de trabalho.

`workspace` representa o ambiente financeiro isolado.
`Id` significa identificador.

O nome indica, portanto, qual Workspace determinado registro pertence.
