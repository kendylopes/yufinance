# Definition of Done

Uma entrega está pronta quando:

- objetivo e regras estão documentados;
- contratos e tipos estão explícitos;
- autorização por Workspace foi validada;
- persistência e migrations estão consistentes;
- casos de uso possuem testes adequados;
- UI trata sucesso, vazio e erro;
- acessibilidade e responsividade foram verificadas;
- check, typecheck, test e build estão verdes conforme o escopo;
- documentação, roadmap/status e changelog foram atualizados.
