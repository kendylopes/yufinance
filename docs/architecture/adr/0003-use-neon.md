# ADR-0003 — Usar Neon

## Contexto

O YuFinance precisa de PostgreSQL gerenciado e compatível com deploy serverless.

## Decisão

Utilizar Neon PostgreSQL.

## Consequências

- Menor carga operacional.
- Integração com Vercel.
- PostgreSQL real.
- Dependência de serviço gerenciado.
